# privacy-policy
Официальная политика конфиденциальности и правила обработки локальных данных для приложения «2call Звонки и СМС».
Дата вступления в силу: 18.08.2026

Настоящая Политика конфиденциальности описывает, как собираются, используются и хранятся ваши данные при использовании мобильного приложения 2call Звонки и СМС (далее — «Приложение»). Разработчиком Приложения выступает физическое лицо.

**1. Назначение приложения и безопасность данных**
Приложение 2call Звонки и СМС является инструментом для локального просмотра статистики звонков и СМС, формирования рейтингов контактов и создания заметок.
Приложение не имеет доступа к сети Интернет  и не содержит встроенных рекламных SDK, систем аналитики или облачной синхронизации. 
Все данные обрабатываются строго на устройстве, никуда не отправляются и не передаются разработчику или третьим лицам.
**2. Какие данные обрабатываются и зачем**
Для корректной работы заявленного функционала Приложение запрашивает системные разрешения Android. Данные извлекаются исключительно после согласия пользователя:
*   **Журнал вызовов (`READ_CALL_LOG`):** используется для отображения статистики звонков, расчета длительности разговоров, детализации и составления рейтингов.
*   **СМС-сообщения (`READ_SMS`):** используется для отображения локального списка сообщений. Текст СМС не собирается и не включается в экспортируемые отчеты.
*   **Контакты (`READ_CONTACTS`):** используется для замены неизвестных номеров на имена из телефонной книги и возможности привязывать локальные заметки к конкретному контакту.
*   **Состояние телефона (`READ_PHONE_STATE`):** используется для определения доступных слотов SIM-карт и операторов с целью фильтрации статистики вызовов.

**3. Экспорт отчетов**
Пользователь имеет возможность вручную сгенерировать отчеты со статистикой в форматах CSV, PDF, XLSX или DOCX. Данные файлы формируются локально. Их дальнейшая передача возможна только по инициативе самого пользователя через системное меню «Поделиться» в выбранное им стороннее приложение.

**4. Хранение и удаление данных**
Созданные пользователем локальные заметки хранятся во внутренней базе данных Приложения. Они могут быть безвозвратно удалены тремя способами:
*   Вручную внутри самого Приложения.
*   Путем очистки данных Приложения через системные настройки Android.
*   При полном удалении Приложения с устройства.

Пользователь вправе в любой момент отозвать любые выданные разрешения (на чтение звонков, СМС или контактов) в настройках ОС Android.
